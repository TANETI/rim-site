진조이니라!

RimWorld 1.6 · 팩 2026.09.01

시작 조립 순서 부품 목록

조립 순서

위에서 아래로 한 번씩만 하면 된다. 각 단계 아래 회색 칸은 거기서 막혔을 때 볼 것이다. 안 막혔으면 읽지 않아도 된다.

01

DLC 넷이 있는지 본다

Royalty, Ideology, Biotech, Odyssey. 하나라도 없으면 이 팩은 뜨지 않는다. 설치기가 먼저 검사하고 멈추므로 여기서 확인만 해 두면 된다.

막혔다면 Steam 라이브러리에서 RimWorld → 속성 → DLC 로 확인한다. 없으면 그 DLC 를 사야 한다.

02

RimWorld 가 OneDrive 아래에 있지 않은지 본다

경로에 OneDrive 가 들어가면 안 된다. 동기화가 게임 파일을 물고 있어 저장과 로드가 깨진다.

막혔다면 Steam 라이브러리를 OneDrive 밖으로 옮긴다. 게임 폴더만 옮기지 말고 라이브러리 단위로 옮겨야 한다.

03

부품을 모은다 — 워크샵 구독

모드 본체는 각자 Steam 에서 구독한다. 재배포를 금지하는 모드가 많아 여기서 옮기지 않고, 설치기도 대신 받아 주지 않는다.

부품 목록에 전부 있다. 다 구독한 뒤 다음 단계로 가면 된다.

몇 개인지 세기 싫다면 먼저 설치기를 받아(4단계) 한 번 돌려라. 없는 것만 골라 링크와 함께 missing-mods.txt 로 뽑아 준다. 그것만 보고 구독한 뒤 다시 돌리면 된다.

04

설치기를 받아 연다

설치기 내려받기 ↓

3.5 MB · SHA-256 07A0FCC57250643D7BC11B1A2992EB163C9F093F3506687EF562AA4C21484F84
안에 설치기와 우리가 만든 모드 19개가 들어 있다. 워크샵 모드는 들어 있지 않다.

아무 데나 풀면 된다. PowerShell 5.1 로 돌고 윈도우에 기본으로 들어 있어 따로 깔 것이 없다. 창으로 쓰려면 Modpack-UI.ps1, 명령줄이 편하면 아래를 쓴다.

powershell -ExecutionPolicy Bypass -File .\installer\Install-Modpack.ps1 -WhatIf

-WhatIf 는 무엇을 할지 보여주기만 하고 아무것도 바꾸지 않는다. 먼저 이걸로 본다.

막혔다면 "이 시스템에서 스크립트를 실행할 수 없습니다" 가 나오면 위 명령의 -ExecutionPolicy Bypass 가 빠진 것이다.

05

세트를 고르고 배열을 만든다

-Apply 를 붙이면 실제로 ModsConfig.xml 을 쓴다. 기존 파일은 날짜가 붙은 이름으로 반드시 백업한 뒤에 덮는다.

.\installer\Install-Modpack.ps1 -Apply -Hygiene lite -Adult off

-Hygiene 는 입문 세트가 none, 기준 세트가 lite 다. -Adult 는 off(기본값) 또는 on. 세트와 무관하게 고른다.

아무것도 안 붙이고 -Interactive 만 주면 설치기가 하나씩 물어본다.

06

RimTalk 을 쓸 거면 API 키를 넣는다 — 선택

이 팩의 폰들은 RimTalk 으로 서로 대화하고 기억한다. 한국어 번역도 여기에 제일 많이 부었다. 다만 대화 생성은 외부 AI 서비스가 하므로 본인의 API 키가 있어야 동작한다.

키가 없어도 게임은 정상이다. RimTalk 만 조용해질 뿐 나머지 123개는 그대로 돈다. 나중에 넣어도 된다.

넣는 곳은 게임 안이다. 설정 → 모드 설정 → RimTalk.

  1. 공급자에서 클라우드를 고르고 Google AI 를 선택한다.
  2. 그 화면의 「무료 API 키 받기」 버튼을 누른다. 브라우저가 열린다.
  3. 받은 키를 Google AI API 키 칸에 붙여넣는다.

무료 등급 모델로 돌아간다. 다른 모델이나 다른 공급자를 쓰려면 같은 창의 고급 설정에 있다.

키를 만들기 싫다면 같은 창에서 로컬 공급자를 고르면 된다. Ollama 나 LM Studio 를 자기 컴퓨터에서 돌리는 방식이라 키가 필요 없다. 대신 그만한 사양이 필요하다.
중요 키는 저 창에만 넣는다. 설치기는 어떤 경우에도 API 키나 Steam 비밀번호를 묻지 않는다. 물어보는 화면이 있으면 그건 이 설치기가 아니다.

07

RimSort 를 받는다

배열을 눈으로 확인하고 고칠 때 쓴다. DDS 변환 도구(todds)가 그 안에 들어 있어 따로 받을 것이 없다.

.\installer\Install-Modpack.ps1 -Apply -WithRimSort

08

텍스처를 DDS 로 바꾼다 — 선택이지만 크게 다르다

부팅이 눈에 띄게 빨라진다. 이 팩 실측으로 데스크탑 기준 약 90초까지 내려갔다. 대신 오래 걸리고(6코어 노트북에서 약 54분) 디스크가 약 6GB 늘어난다. PNG 는 지우지 않으므로 todds --clean 으로 언제든 되돌린다.

.\installer\Install-Modpack.ps1 -Apply -WithRimSort -WithDds
알아 둘 것 가로·세로가 4의 배수가 아닌 이미지는 DDS 가 만들어져도 게임이 로드를 거부한다. 설치기가 변환 뒤 자동으로 걸러 낸다.

09

게임을 켠다

첫 부팅은 오래 걸린다. 모드 목록에 빨간 느낌표가 없는지만 본다.

막혔다면 빨간 느낌표는 대개 구독이 덜 끝난 것이다. Steam 을 한 번 다시 켜고 다운로드가 끝나기를 기다린 뒤 다시 부팅한다.

10

나중에 — 자작 모드만 갱신한다

워크샵 모드 108개는 Steam 이 알아서 갱신한다. 챙겨야 하는 것은 우리가 만든 19개뿐이다.

.\installer\Install-Modpack.ps1 -Apply

설치와 갱신이 같은 명령이다. 처음이면 깔고, 이미 있으면 바뀐 것만 덮는다.

덮어쓰기 전에 기존 설치본을 통째로 복사해 두고, 받은 것이 온전한지 무결성 색인과 대조한다. 한 파일이라도 어긋나면 그 모드는 건드리지 않는다.

모드 본체는 각자 Steam 워크샵에서 받는다. 이 사이트가 옮기는 것은 우리가 만든 것과 목록·순서뿐이다. 워크샵 모드 다수가 재배포를 금지한다.

무결성 색인 local-mods.index.json 은 손상 검출용이다. 서명이 아니다 — 색인도 같은 배포처에서 온다.
